# Game architecture & network protocol

This is the contract between the server scripts, the client UI and the map.
Anyone (human or AI) changing one side must keep the other sides in sync.

## Folder layout (Rojo → Roblox)

| Repo path | Roblox location | What |
|---|---|---|
| `src/ReplicatedStorage/Shared/` | `ReplicatedStorage.Shared` | data + helpers both sides use (`Config`, `Fighters`, `Remotes`, `Format`) |
| `src/ServerScriptService/Main.server.luau` | `ServerScriptService.Main` | boots every service |
| `src/ServerScriptService/Server/` | `ServerScriptService.Server` | services (Data, Queue, Match, Shop, Rewards, Leaderboard), Renderer, FighterModel, Bot |
| `src/ServerScriptService/Sim/` | `ServerScriptService.Sim` | pure-Luau battle simulation + `Abilities/<FighterId>.luau` |
| `src/StarterPlayerScripts/` | `StarterPlayer.StarterPlayerScripts` | client: UI, camera, aiming, effects |
| `src/Workspace/Lobby.model.json` | `Workspace.Lobby` | generated by `tools/build_maps.py` |
| `src/Workspace/Arenas.model.json` | `Workspace.Arenas` | generated by `tools/build_maps.py` |

## World naming contract (the map must provide these)

Coordinates: the lobby island is centred on (0, 0, 0), north = +Z. Arena templates sit in a row far away
(they are moved to ServerStorage at runtime and cloned into free slots at Y = 1000 for each match).

### `Workspace.Lobby` ("Shonen Plaza", framework §9.1)
* `SpawnLocation` parts (8) under the Spawn Gate.
* `QueuePads` (Folder) containing pad **Models**, each with:
  * attributes `Mode` = `"1v1"` | `"2v2"` | `"Bot"`, `Capacity` = 2 | 4 | 1, and for bot pads `Difficulty` = `"Easy"` | `"Normal"` | `"Hard"` | `"TryOut"`
  * a part named `Pad` (players stand on it; its top surface is the stand point)
  * a part named `Display` with a `SurfaceGui` → `TextLabel` named `Text` (server writes `"0/2 PLAYERS | WIN 100+"`)
* `SummonShrines` (Folder) with shrine Models, each with attribute `Banner` = `"basic"` | `"standard"` | `"featured"` and a part named `Prompt` (server adds a ProximityPrompt that opens the Summon screen on that banner).
* `Leaderboards` (Folder) with board Models; attribute `Stat` = `"Wins"` | `"BestStreak"` | `"Level"` | `"Index"`; a part `Screen` with a `SurfaceGui` containing a `Frame` named `List` (server fills rows).
* `QuestBoard`, `CodeBoard`, `WhatsNewBoard` Models with a part `Prompt` (opens Quests / Codes; WhatsNew has a SurfaceGui TextLabel `Text` the server fills with the version + newest code).
* `HallOfHeroes` (Folder) with 30 pedestal Models, attribute `Slot` = 1..30 and a part `Top` (the server places a mini fighter model on each).
* `ClashTV` Model with 4 parts `Screen1..4`, each with SurfaceGui → TextLabel `Text` (server shows live match info).
* `SenseiMaru` Model (mascot NPC) with a part `Prompt` (opens the help/tutorial tip).
* `QuickMatchHint` (optional) and decorative everything else.
* Parts/Models may carry `SpinSpeed` (deg/s) or `BobHeight` (studs) attributes for LobbyService animation.

### `Workspace.Arenas`
One **Model per arena template**, attributes:
* `ArenaId` (e.g. `"A1"`), `Theme` (display name, e.g. "Sensei Dojo"), `Pool` = `"neutral"` | `"gimmick"`, `Mode` = `"1v1"` | `"2v2"`
* `HalfX`, `HalfY` — half the play-area size along world X and Z (A1: 24, 24)
* `Gimmick` = `"none"` | `"waves"` | `"portals"` | `"cannons"` | `"puddles"` | `"pillars"`
Children:
* `Floor` — part whose **top surface centre** is the fight origin (simulation (0, 0)). The play rectangle is `2*HalfX` × `2*HalfY`, centred on it, axis-aligned with world X/Z. Walls stand exactly on its edges, 5 studs high.
* `Stand1` (south balcony, −Z side) and `Stand2` (north balcony, +Z side) — 10 × 6 parts, 4 studs above the floor, behind the wall, where player avatars stand.
* `CameraPoint` — part whose CFrame is the match camera (≈60° down, FOV 40, frames arena + both balconies).
* `Obstacles` (Folder, optional) — round pillars the simulation collides with: each part is a vertical cylinder; attribute `Radius` (studs). Its X/Z position relative to the Floor top centre is used.
* `Portals` (Folder, optional) — parts `PortalA` / `PortalB` (attribute `Radius`).
* `Puddles` (Folder, optional) — flat discs with attribute `Radius`.
* Everything else (walls, decoration, lights) is visual only. Decorations stay outside the walls.

## Remotes (`ReplicatedStorage.Remotes`, created by the server at start)

### RemoteEvents
| Name | Direction | Payload |
|---|---|---|
| `Data` | S→C | full profile view (see below), sent on join and after every change |
| `Notify` | S→C | `{text, color?, sound?}` toast message |
| `Match` | S→C | match phase messages (see below) |
| `MatchFx` | S→C | array of client fx `{kind = "shake"|"flash"|"banner"|"ultReady"|"callout", ...}` |
| `MatchState` | S→C (UnreliableRemoteEvent) | battle HUD snapshot 10×/s: `{time, overtime, units = {{id, team, ownerId, fighterId, hp, maxHp, charge, ultReady, cd1, cd1Max, alive}}}` |
| `Queue` | S→C | `{inQueue = bool, mode, count, capacity, padName, waitTime}` |
| `MatchAction` | C→S | `{action = "pick", fighterId}` · `{action = "freePick", fighterId}` · `{action = "reroll"}` · `{action = "aim", angle}` (radians, 0 = toward +X) · `{action = "lock"}` · `{action = "ult"}` · `{action = "swap"}` · `{action = "leaveQueue"}` · `{action = "forfeit"}` |
| `UIAction` | C→S | `{action = "claimQuest", id}` · `{action = "claimOnline", tier}` · `{action = "claimDaily"}` · `{action = "setSetting", key, value}` |

### RemoteFunctions
| Name | Call | Returns |
|---|---|---|
| `Summon` | `(bannerId, count)` | `{ok, error?, results = {{fighterId, rarity, isNew, refund?}}}` |
| `RedeemCode` | `(code)` | `{ok, message}` |
| `BuyProduct` | `(productKey)` | `{ok, message}` (prompts MarketplaceService) |

### `Match` messages (S→C), field `phase`
| phase | extra fields |
|---|---|
| `"start"` | `matchId, mode, arena (Model), myTeam, players = {{userId, name, team, isBot}}, hearts = {[team] = n}, round` |
| `"pick"` | `round, endsAt (workspace:GetServerTimeNow()), options = {fighterId x3}, freePickAvailable, rerollCost, gems` |
| `"opponentPicked"` | `team, fighterId` (sent as soon as an enemy locks a pick, so you can counter-pick) |
| `"aim"` | `endsAt, myStart = {x, y}, fighterId, picks = {{team, userId, fighterId}}` |
| `"fight"` | `round` |
| `"strike"` | `winnerTeam, loserTeam, hearts = {[team] = n}` |
| `"results"` | `won, coins, xp, gems?, levelUp?, newLevel?, hearts, stats` |
| `"ended"` | (camera back to normal, UI closes) |

## Profile view (`Data` payload)
```lua
{
  coins = 1200, gems = 40, level = 3, xp = 40, xpNeeded = 150,
  owned = { [fighterId] = copies },          -- copies >= 1 means owned
  stats = { wins = 0, losses = 0, matches = 0, streak = 0, bestStreak = 0 },
  quests = { { id, text, progress, goal, reward = {coins = 100}, claimed } },
  online = { seconds = 600, claimed = { [tierIndex] = true } },
  daily = { streak = 2, canClaim = true },
  x2Until = 0,           -- os.time() when the x2 coins boost ends
  pity = { [bannerId] = n },
  settings = { music = true, sfx = true },
  passes = { VIP = false, DoubleCoins = false },
}
```
